# GitHub Copilot Demo — Simple Browser Web App

This demo requires no .NET, Node.js, package manager, or local server. It is a static HTML/CSS/JavaScript application.

## Run it
1. Extract this ZIP.
2. Open `index.html` in your browser.
3. Try submitting a leave request.
4. For the Copilot demo, open the folder in VS Code if allowed, or upload/push the files to a GitHub repository and edit them with the GitHub web editor/Copilot features available to your account.

## Demo story
- Existing app: simple leave request form and basic JavaScript.
- Modernisation task: ask Copilot to improve validation, user feedback, accessibility, and code organisation without changing the app's purpose.
- Then add a leave balance summary and filter the submitted requests.

## Important
This is a front-end-only demo. Requests are stored in browser memory and disappear when the page is refreshed. It has no login, backend, or real HR integration. Do not enter real employee data.
